## Nota de exactitud
La documentación refleja los requisitos y funcionalidades trabajadas durante el desarrollo. Los nombres exactos de tablas, columnas, RPC, variables de configuración y políticas deben cotejarse con el código fuente y las migraciones SQL vigentes antes de una auditoría o despliegue. No se incluyen secretos ni credenciales.
